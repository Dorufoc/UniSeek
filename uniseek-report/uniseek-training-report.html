第二章

项目阶段 — 前言

2.1 项目背景

项目起源（痛点）

大学生兼职市场长期存在信息不对称问题——求职者难以找到真实可靠的兼职信息，企业HR缺乏高效的招聘渠道。传统兼职平台存在虚假信息泛滥、沟通效率低下、管理流程不透明等痛点。基于此，项目团队决定开发UniSeek优寻兼职招聘平台。

数据基础

项目数据库基于MySQL 8，包含用户表（user）、企业表（enterprise）、职位表（task）、投递申请表（task_application）、简历表（resume）、聊天表（chat_message/chat_session）、通知表（notification）、分类表（category）、行政区划表（region）、日报统计表（daily_statistics）、操作日志表（operation_log）等14张业务表，涵盖平台运营全链路数据。

平台定位

UniSeek优寻定位于面向高校学生的兼职招聘垂直平台，打造"求职-投递-沟通-录用-结算"全流程闭环服务。

四个核心驱动

信息真实

企业资质审核 + 实名认证双认证体系

沟通高效

投递后自动创建聊天会话

流程透明

投递状态全生命周期可追溯

数据驱动

运营日报 + 数据大屏可视化

服务对象与价值

  • 求职者：获得真实可靠的兼职机会，全流程线上化
  • 企业HR：精准触达求职者，高效管理招聘流程
  • 平台运营：通过数据看板实时掌握平台健康度

2.2 系统概述

2.2.1 项目目标

系统功能目标：实现用户注册登录、实名认证、企业资质审核、职位发布/审核/搜索/投递、简历管理、即时聊天、消息通知、投递状态流转、运营统计看板、数据大屏可视化、操作日志审计、用户权限管理等核心功能。

性能/质量目标：系统稳定性——服务可用性 ≥ 99.9%；响应速度——核心接口响应 ≤ 500ms，列表分页 ≤ 1s；可维护性——代码分层清晰，统一异常处理，完善日志审计；安全性——密码独立盐值MD5加密，JWT无状态鉴权，身份证AES加密存储，角色权限控制。

用户/服务目标：求职者——快速发现合适的兼职岗位并完成投递；企业HR——高效管理招聘流程，筛选合适人才；运营管理员——通过数据监控平台运营状况，管理企业资质和职位审核。

技术/架构目标：前后端分离架构，后端Spring Boot 2.2.2 + MyBatis + MySQL 8，前端Vue 3 + Element Plus + Pinia + ECharts，鸿蒙端ArkTS 6.1.1独立App，统一API接口规范。

交付/成果目标：交付一个可运行的兼职招聘网站（Vue前端+Java后端API）、一个鸿蒙原生求职App（ArkTS）、一个数据可视化大屏。

本人负责模块覆盖了三端：

3.5 示例用例

UC1：求职者投递职位

参与者：求职者 | 前置条件：已完成实名认证且有简历 | 后置条件：投递记录创建 + 聊天会话自动创建 + HR收到通知

主要成功场景：

  1. 求职者浏览职位列表，按条件筛选
  2. 点击感兴趣的职位进入详情页
  3. 点击"立即投递"按钮
  4. 系统校验实名认证状态
  5. 校验投递资格（非重复投递、未满员）
  6. 创建投递记录，状态为"已投递"
  7. 生成简历快照
  8. 自动创建求职者与HR的聊天会话
  9. 发送系统通知给HR

UC2：HR审核投递

参与者：企业HR | 前置条件：有投递记录 | 后置条件：状态变更 + 通知求职者

主要成功场景：

  1. HR进入简历池页面，查看投递列表
  2. 点击某条投递查看详情和简历
  3. 选择状态变更（待面试/已录用/已淘汰）
  4. 填写处理备注
  5. 系统执行状态流转，乐观锁防止并发
  6. 发送系统通知给求职者

UC3：运营管理员审核企业资质

参与者：运营管理员 | 前置条件：有企业提交资质 | 后置条件：企业状态变更 + 通知HR

主要成功场景：

  1. 管理员进入企业资质审核页面
  2. 查看待审核企业列表
  3. 点击查看企业详情和营业执照
  4. 选择"通过"或"驳回"并填写审核意见
  5. 系统更新企业状态
  6. 发送审核结果通知给HR

代码片段一：JWT鉴权拦截器（Java）

Java 
// JwtInterceptor.java - JWT无状态鉴权拦截器
@Component
public class JwtInterceptor implements HandlerInterceptor {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Override
    public boolean preHandle(HttpServletRequest request,
            HttpServletResponse response, Object handler) {
        // 从请求头获取Token
        String token = request.getHeader("Authorization");
        if (token == null || !token.startsWith("Bearer ")) {
            throw new AuthException("未登录或Token已过期");
        }

        // 解析JWT并校验过期
        Claims claims = JwtUtil.parseToken(token.substring(7));
        if (claims == null) {
            throw new AuthException("Token无效或已过期，请重新登录");
        }

        // 将用户信息存入请求上下文
        request.setAttribute("userId", claims.get("userId"));
        request.setAttribute("role", claims.get("role"));
        return true;
    }
}

代码片段二：投递申请业务逻辑（Java Service）

// ApplicationService.java - 投递申请核心业务
@Service
public class ApplicationService {

    @Autowired
    private TaskApplicationDao applicationDao;
    @Autowired
    private TaskDao taskDao;
    @Autowired
    private ChatSessionDao chatSessionDao;

    // 投递职位 - 含事务、乐观锁、简历快照、会话创建
    @Transactional
    public Result applyForTask(Long userId, Long taskId) {
        // 1. 校验实名认证
        User user = userDao.selectById(userId);
        if (user.getRealNameStatus() != 1) {
            return Result.error("请先完成实名认证");
        }
        // 2. 乐观锁防超录
        Task task = taskDao.selectById(taskId);
        if (task.getApplyCount() >= task.getHeadcount()) {
            return Result.error("该职位已满员");
        }
        // 3. 创建投递记录 + 生成简历快照
        TaskApplication app = new TaskApplication();
        app.setTaskId(taskId);
        app.setUserId(userId);
        app.setStatus(0); // 已投递
        app.setResumeSnapshot(buildSnapshot(userId));
        applicationDao.insert(app);
        // 4. 更新职位已申请数
        taskDao.incrementApplyCount(taskId, task.getVersion());
        // 5. 自动创建聊天会话
        createChatSession(userId, task.getEnterpriseId(), taskId);
        return Result.success("投递成功");
    }
}

代码片段三：鸿蒙端HTTP请求Service（ArkTS）

ArkTS 
// HttpService.ets - 封装网络请求
import { http } from '@kit.NetworkKit';

export class HttpService {
  private baseUrl: string = 'http://10.0.0.2:8080/api';
  private token: string = '';

  setToken(token: string): void {
    this.token = token;
  }

  async request<T>(method: string, url: string, data?: object): Promise<T> {
    return new Promise<T>((resolve, reject) => {
      const httpRequest = http.createHttp();
      httpRequest.request(
        this.baseUrl + url,
        {
          method: method,
          header: {
            'Content-Type': 'application/json',
            'Authorization': 'Bearer ' + this.token
          },
          extraData: data
        },
        (err, resp) => {
          if (err) { reject(err); return; }
          resolve(resp.result as T);
        }
      );
    });
  }

  get<T>(url: string): Promise<T> {
    return this.request<T>('GET', url);
  }

  post<T>(url: string, data: object): Promise<T> {
    return this.request<T>('POST', url, data);
  }

  put<T>(url: string, data: object): Promise<T> {
    return this.request<T>('PUT', url, data);
  }
}
